# LAN Cam OBS 0.4.2

Aplicativo local para usar o celular como fonte de navegador no OBS e como emissor para uma webcam virtual DirectShow no Windows.

## Novidades desde 0.3.0-rc.1

- Um único atalho **LAN Cam OBS**, com as áreas **Sistema**, **Configuração** e **LAN Cam**.
- Controles para ligar/desligar transmissões, instalar/reparar/remover a webcam e configurar HTTPS pelo painel.
- Estado do driver e do HTTPS no painel; detalhes de falhas de configuração na própria tela.
- QR Code local para o celular e links para OBS, visualizadores e USB/ADB.

## Correções

- A ponte cria o evento de sincronização `UnityCapture_Want` exigido pelo driver.
- A atualização encerra o runtime dedicado desta instalação mesmo sem PID válido e aguarda a liberação do executável.
- O instalador executa o novo script de encerramento antes de substituir os arquivos antigos.
- Drivers idênticos não são sobrescritos quando a DLL está carregada; atualizações bloqueadas mostram uma orientação para fechar os aplicativos que usam a câmera.
- O HTTPS resolve o executável real do mkcert, evitando a falha do link simbólico do WinGet no PowerShell 5.1.
- O registro da webcam aguarda o `regsvr32` e lê o código do processo com `Start-Process -Wait -PassThru`, evitando o falso erro com código vazio.
- O registro x64 é prioritário; o componente x86 é opcional.

## Validação e pendências

- Cinco testes automatizados do servidor passaram, incluindo sinalização/JPEG, QR, controle do sistema e proteção das ações locais.
- Regressões Windows passaram para processos GUI com sucesso/falha, códigos reais do regsvr32, DLL bloqueada e encerramento restrito ao runtime dedicado.
- A ponte transmitiu uma imagem de teste pelo driver DirectShow em 1280×720; a configuração corrigida retornou código 0 na máquina de teste.
- **Pendência conhecida:** o Windows/DirectShow lista “LAN Cam Webcam”, mas a câmera ainda não apareceu na lista do Google Meet no Edge na máquina de teste. A causa permanece em investigação. A validação DirectShow não comprova compatibilidade com Meet, Zoom ou Teams. Esta distribuição é uma pré-release.

## Instalação

Baixe `LAN-Cam-OBS-Setup-0.4.2-win-x64.exe` e, opcionalmente, confira o SHA-256 com o arquivo `.sha256` anexo. O pacote inclui o Node.js; não exige Python nem instalação de pacotes npm. É destinado a Windows x64 e não possui assinatura de código.

Abra **LAN Cam OBS → Configuração** para preparar webcam e Wi-Fi. O Windows pode pedir autorização administrativa. O certificado público ainda precisa ser instalado manualmente no celular. O aplicativo transmite vídeo, sem microfone.

Para atualizar, execute o instalador; a chave e os certificados locais são preservados. Os atalhos auxiliares antigos são removidos. Se o navegador não atualizar a lista de câmeras, encerre todas as suas janelas e processos quando puder sair da reunião e teste novamente; isso é uma etapa de diagnóstico, não uma correção confirmada para a pendência do Meet.
